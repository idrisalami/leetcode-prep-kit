Primitive 1: the invariant

This is the centre of the module. Everything else is bookkeeping.

RuleThe answer, if it exists, is inside the current range.
Every line in the loop body has one job: leave that sentence true. Writing hi = mid - 1 claims "nothing at mid or beyond can be the answer."

Primitive 2: the range convention

Pick one before writing the loop. The rest of the code is read off that choice.

Interview tipSay the convention out loud before you code: "I'll use half-open, so hi starts at len(nums)."
