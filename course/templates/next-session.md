# Next session

**What this file is for.** A new Claude session starts with no memory of the last one. This file is the handoff: it says where you are, what comes next, and what to watch for, so a fresh chat can pick up from the repo alone. Claude reads it first whenever `my-prep/` exists.

**When it is rewritten.** At the end of every step (discovery, module 00, the diagnostic, scoring and plan, each block), and before a session that ends partway through one. Each rewrite replaces the whole file, so it always describes the *next* session, never the last one.
